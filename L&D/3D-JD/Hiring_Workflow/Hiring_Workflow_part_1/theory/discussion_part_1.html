3. Assessment Platform – Live Demo
3.1 AI-Generated Question Validation
Questions generated by AI are evaluated against a quality score:
• Score Below 75%: question goes to Rejected.
• Score 75%–80%: question goes to Pending Review.
• Score above 80%: question is automatically approved.

Assessment Settings and Learner Flow
Once the assessment is created:
• Configure Assessment – Review duration, attempts, instructions, and other required
settings.
• Schedule Assessment – Set the assessment start date/time and end date/time.
• Invite Learners – Add learners using their name and email ID and send the invitation.
• Learner Dashboard – The scheduled assessment will appear on the learner’s
dashboard based on the configured schedule.
• Invited Learners – Use the Invited Learners tab to view learner details and
invitation/assessment status.
• Cancel Invite – Use Cancel Invite if an invitation needs to be withdrawn.

3.3 Web Proctoring
• Web proctoring detects violations with a zero-tolerance policy.
• It calculates an Integrity Index, categorised as Low, Medium or High.
• The Integrity Index should be taken into consideration when it shows a higher value and
the exam is conducted in the presence of an invigilator.

Summary of the discussion
The main feedback was that you need a much stronger end-to-end understanding of the
assessment platform, rather than only knowing individual activities such as blueprint creation,
question review, or assessment scheduling.
1. Purpose of the platform
• The platform is being built internally so Cognizant can become more self-reliant for
assessment creation and delivery.
• One objective is to reduce dependency on third-party assessment platforms such as Mettl
and HackerRank, including the cost and turnaround time associated with them.
• You should understand not only how each feature works, but also why the platform and
each feature are needed.
2. Understand the complete assessment flow
You were asked to document and understand the sequence:
Requirement → Blueprint → Question Bank/QB Engine → Question Review → Assessment
Creation → Assessment Configuration → Scheduling → Learner Dashboard → Assessment
Attempt → Submission → Feedback/Result
Key point: the blueprint is the base. It defines things such as:
• Sections
• Skills/topics
• Number of questions
• Difficulty/proficiency
• Duration/section timing
• Scores and other assessment attributes
The QB engine then uses these requirements to generate/pull the required questions. When an
assessment is needed, the Assessment Admin selects the appropriate blueprint and creates
the assessment.
