Summary of the Discussion
The discussion was mainly about understanding the broader scope of the SkillSpring
Assessment Platform, especially new requirements coming from GenC Skilling, beyond the
hiring-related assessment requirements you have been working on.
1. Assessment Platform scope is expanding
So far, your work has primarily focused on hiring assessments, including:
• Blueprint requirements
• Assessment flow
• Assessment settings
• Scheduling
• Reports
However, the platform under SkillSpring also needs to support other use cases, including:
• Evidence-Based Assessments
• Simulation assessments
• AI/Interview Bot-based interim evaluations
• GenC Skilling assessments
2. Evidence-Based Assessment
This is intended mainly for experienced employees.
Employees may be able to:
• Upload evidence/projects they have worked on.
• Use this evidence to demonstrate their competency.
• Have the system validate whether their work actually corresponds to the claimed PL3, PL4,
etc. proficiency level.
3. Interview Bot / Interim Evaluation
An Interview Bot is also being integrated with the assessment platform.
The idea is to:
• Generate questions based on curriculum, skills and topics.
• Conduct mock/interim evaluations.
• Reduce dependency on SMEs or other people conducting every interim evaluation
manually.
• Continue using human evaluation where appropriate for final evaluations.
4. Assessment Admin flow
As an Assessment Admin, the expected flow is:
Manage Assessments → Assessment Library → Select Assessment
The admin should have access to four key areas:
1. Questions
2. Settings
3. Scheduling
4. Learners
Within Settings, areas include:
• General Settings
• Test Integrity
• Publishing Category
• Assessment Category
5. New GenC Skilling publishing category
A new GenC Skilling publishing category is being introduced.
The publishing category identifies what requirement/use case the assessment is intended for.
For example:
• Hiring
• Internal assessment
• GenC Skilling
When GenC Skilling is selected, additional skilling-specific settings/requirements can be
displayed.
6. Qualifier assessments
For GenC Skilling, an assessment may be classified as a Qualifier.
A qualifier can determine whether a learner is allowed to move to the next stage of the learning
journey.
Example:
Stage 1: Core/basic skills → Qualifier → Pass → Next stage
If the learner does not clear it, there may be consequences after the permitted number of attempts.
Therefore, additional settings are being considered for:
• Whether an assessment is a Qualifier
• Maximum permitted attempts
• Restrictions on rescheduling/re-attempts
This differs from the current behaviour where assessments may be rescheduled multiple times
with fewer restrictions.
7. GenC Skilling report requirements
The existing hiring report was intentionally kept relatively simple.
However, the GenC Skilling team requires additional report fields, so a separate/set of
enhanced reporting requirements has been groomed.
Some fields overlap with hiring reports, such as:
• Scores
• Assessment start information
• Access window
But Skilling requires additional detailed fields.
8. Integrity Index and proctoring violations
Another major requirement is detailed reporting of assessment integrity violations.
The platform may use mechanisms such as:
• Web proctoring
• Safe Exam Browser / Full Integrity Mode
Different violations can have different weightages.
There are also zero-tolerance violations. If one of these violations occurs, the learner's Integrity
Index may automatically be pushed to the lowest level.
The comparison made was with the credibility/integrity filtering currently done in assessment
reports.
9. Hiring vs Skilling integrity reporting
There is an important reporting difference:
Hiring report
• Primarily provides the final credibility/integrity value.
GenC Skilling report
• Integrity Index
• Violation count
• Violation details
• Supporting logic/data used to derive the Integrity Index
This allows the Skilling team to understand why a learner received a particular integrity score,
rather than seeing only the final value.
An additional worksheet containing this information has therefore been proposed for the Skilling
report.
10. Question Bank
You were also asked to go through the Manage Question Bank functionality.
For MCQs, a Content Admin should be able to:
• Filter questions by question type.
• View an MCQ.
• Edit the question text.
• Edit/add answer options.
• Select the correct answer.
• Approve or reject the question.
